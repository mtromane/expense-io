# ADR-010 · Fonctionnalité du live coding

* Statut : Proposée, à valider par l'équipe
* Décision source : D10

## Contexte
La fonctionnalité est imposée par les professeurs le jour de la soutenance.

## Décision
Rien à coder à l'avance. La préparation porte sur la capacité de la codebase et de l'agent IA à absorber n'importe quelle fonctionnalité : section « Ajouter une fonctionnalité » dans `AGENTS.md`, README par module, règles ESLint bloquantes, répétition à blanc.

## Alternatives
Aucune : identifiant conservé pour ne pas renuméroter les décisions.

## Conséquences
`AGENTS.md` décrit le chemin use case → port → adapter → route → contrat → test.
